Publications

2025

PreServe: Hierarchical Prediction-based Management for LMaaS Systems

Yujie Huang, Jiazhen Gu, Zhihan Jiang, Michael R. Lyu

ICSE 2025 - 47th International Conference on Software Engineering

Ottawa, Canada • April 27 - May 3, 2025

We propose PreServe, a hierarchical prediction-based management system that optimizes resource allocation and scheduling for Large Language Model as a Service (LMaaS) platforms through multi-level predictions of request arrival patterns, execution times, and resource demands.

arXiv Code

LLMPrism: Black-box Performance Diagnosis for Production LLM Training Platforms

Zhihan Jiang, Yujie Huang, Haiyu Huang, Jiazhen Gu, Yilun Wang, Pengfei Chen, Michael R. Lyu

arXiv preprint arXiv:2505.00342

LLMPrism addresses the challenge of diagnosing performance issues in production LLM training platforms through black-box monitoring, providing automated root cause analysis without requiring access to internal system details or source code.

arXiv

Why Does the LLM Stop Computing: An Empirical Study of User-Reported Failures in Open-Source LLMs

Zhihan Jiang, Jiazhen Gu, Yujie Huang, Haiyu Huang, Dongping Chen, Yilun Wang, Pengfei Chen, Michael R. Lyu

arXiv preprint arXiv:2601.13655

Through systematic analysis of user-reported issues in open-source LLM projects, we identify and categorize common failure patterns, root causes, and their implications for improving LLM system reliability in production environments.

arXiv

Cloud-OpsBench: A Reproducible Benchmark for Agentic Root Cause Analysis in Cloud Systems

Yilun Wang, Guangba Yu, Haiyu Huang, Yujie Huang, Pengfei Chen, Michael R. Lyu

arXiv preprint arXiv:2603.00468

Cloud-OpsBench provides a standardized, reproducible benchmark for evaluating AI agents in automated root cause analysis tasks within cloud environments, enabling systematic comparison of different approaches to operational problem diagnosis.

arXiv
